這陣子，有好多人跟我詢問我們家小朋友理毛都用哪一個廠牌的電剪？

其實，我沒有特別使用哪一個廠牌的電剪，
唯一的需求，是要選擇可以調整剃刀長度的電剪，

因為這種電剪，可以方便我選擇要使用的長度，
只是在剪的過程當中，只要一剪下就不要再變動長度，要一路剪下去，這樣剪完小朋友就可以有一個平順的毛髮了。

狀況大概是像這樣，順著毛髮剪下去，就會剪得很漂亮。
